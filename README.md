# Thai ID Card OCR API

API สำหรับสกัดข้อมูลจากหน้าบัตรประชาชนไทยโดยอัตโนมัติ โครงการนี้พัฒนาด้วย FastAPI สำหรับจัดการฝั่งเซิร์ฟเวอร์, OpenCV (อัลกอริทึม SIFT และ Homography) สำหรับปรับแก้ความเอียงและจัดหน้าบัตรให้ตรงเป๊ะ และ EasyOCR สำหรับการอ่านข้อความ (รองรับทั้งภาษาไทยและภาษาอังกฤษ)

## คุณสมบัติหลัก (Key Features)

* **Auto-Alignment:** ระบบสามารถตรวจจับจุดเด่นของภาพ (Keypoints) เพื่อดัดรูปภาพบัตรที่ผู้ใช้งานถ่ายมาให้มีความตรงและได้สัดส่วนเท่ากับภาพต้นแบบ (Template) เสมอ
* **Configuration-Driven ROI:** ควบคุมพิกัดการตัดภาพ (Crop) ของแต่ละฟิลด์ข้อมูลได้ผ่านไฟล์ `config.yaml` ทำให้สามารถปรับจูนความแม่นยำได้โดยไม่ต้องแก้ไขโค้ดหลัก
* **Image Pre-processing:** มีระบบขยายสัดส่วนภาพ (Upscaling) และลดจุดรบกวน (Noise Reduction) ก่อนส่งให้ OCR ประมวลผล ช่วยเพิ่มความแม่นยำในการอ่านตัวหนังสือขนาดเล็ก
* **API Documentation:** มีหน้าเอกสารและระบบทดสอบ API ในตัวผ่าน Swagger UI

วิธีการติดตั้ง (Installation)
ทำการ Clone โปรเจกต์ลงมาที่เครื่องคอมพิวเตอร์ของคุณ

Bash
git clone [https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git](https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git)
cd YOUR_REPO_NAME
สร้างและเปิดใช้งาน Virtual Environment

Bash
python -m venv venv
venv\Scripts\activate
ติดตั้ง Library ที่ระบุไว้ใน requirements

Bash
pip install -r requirements.txt
การเปิดใช้งานเซิร์ฟเวอร์ (Running the Server)
ในการเปิดใช้งาน API Server ให้เปิด Terminal และรันคำสั่ง Uvicorn ดังต่อไปนี้:

Bash
uvicorn main:app --reload --reload-include "*.yaml"
คำอธิบายคำสั่ง:

main:app คือการชี้ไปที่ตัวแปร app ในไฟล์ main.py

--reload จะสั่งให้เซิร์ฟเวอร์รีสตาร์ทตัวเองอัตโนมัติเมื่อมีการบันทึกการแก้ไขไฟล์ Python

--reload-include "*.yaml" เป็นการขยายขอบเขตให้เซิร์ฟเวอร์รับรู้การเปลี่ยนแปลงในไฟล์พิกัด config.yaml ด้วย

การทดสอบ API (Testing)
เมื่อเซิร์ฟเวอร์ทำงาน (แสดงข้อความ Application startup complete ใน Terminal) สามารถเข้าไปทดสอบระบบได้ตามขั้นตอนต่อไปนี้:

เปิด Web Browser และเข้าไปที่ URL: http://localhost:8000/docs

คลิกที่แถบสีเขียว POST /extract-id

คลิกปุ่ม Try it out (มุมขวาบนของแถบ)

คลิกปุ่ม Choose File เพื่ออัปโหลดรูปภาพบัตรประชาชน

คลิกปุ่ม Execute สีฟ้าด้านล่างเพื่อเริ่มการประมวลผล

เลื่อนลงมาที่หัวข้อ Server response เพื่อดูผลลัพธ์ข้อมูลที่สกัดได้ในรูปแบบ JSON

คำแนะนำในการเลือกรูปภาพสำหรับทดสอบ (Image Selection Guidelines)
เพื่อให้ระบบทำงานได้อย่างมีประสิทธิภาพสูงสุดและไม่เกิดข้อผิดพลาดในการประมวลผล ควรเลือกรูปภาพทดสอบตามเกณฑ์ดังนี้:

ไม่มีลายน้ำพาดทับข้อความ: หลีกเลี่ยงรูปภาพจาก Stock Photo ที่มีลายน้ำ (Watermark) พาดทับบริเวณตัวอักษร เนื่องจาก AI จะตีความลายเส้นเหล่านั้นเป็นส่วนหนึ่งของตัวอักษร ทำให้ผลลัพธ์ผิดเพี้ยน

ความคมชัดและแสงสว่าง: ตัวหนังสือบนบัตรควรมีความคมชัด แสงสว่างเพียงพอ ไม่มืดหรือสว่างจ้าจนมองไม่เห็นรายละเอียด

หลีกเลี่ยงแสงสะท้อน (Glare): ระวังแสงแฟลชหรือแสงสะท้อนบนพื้นผิวบัตร (โดยเฉพาะบริเวณชื่อและนามสกุล) เพราะจะทำให้รายละเอียดตัวอักษรหายไป

สัดส่วนภาพที่เหมาะสม: แม้ระบบจะมี SIFT ช่วยดัดภาพ แต่ควรเลือกรูปที่ถ่ายหน้าตรง หรือเอียงเพียงเล็กน้อย และเห็นขอบบัตรครบทั้ง 4 ด้าน เพื่อให้โมเดลสามารถคำนวณสัดส่วนเทียบกับ Template ได้อย่างสมบูรณ์
